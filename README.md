# OneVerse – Uttar Pradesh Local Services

## About the Project
OneVerse is a local services platform designed to help users easily discover and access different services available in their city.

The platform brings multiple local services together in one place, making it easier for users to find service providers and contact them.

## Features
- Local service discovery
- Multiple service categories
- Service provider details
- Contact information
- Simple and user-friendly interface
- City-based local services

## Technology Used
- HTML
- CSS
- JavaScript

## Project Purpose
The main goal of OneVerse is to provide a simple digital platform where users can find and connect with local service providers conveniently.
